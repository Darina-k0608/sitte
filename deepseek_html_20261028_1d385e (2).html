Метод координат в стереометрии

Интерактивный тренажёр для подготовки к заданию №15 ЕГЭ

Уравнение прямой по двум точкам

Каноническое уравнение прямой

(x − x₁) / (x₂ − x₁) = (y − y₁) / (y₂ − y₁) = (z − z₁) / (z₂ − z₁)

где s = {x₂ − x₁; y₂ − y₁; z₂ − z₁} — направляющий вектор.

Расстояние от точки до прямой

Формула расстояния

d = |M₀M₁ × s| / |s|

где M₁ — точка на прямой, s — направляющий вектор.

Уравнение плоскости по трём точкам

Определитель

|x−x₁   y−y₁   z−z₁ ;
x₂−x₁   y₂−y₁   z₂−z₁ ;
x₃−x₁   y₃−y₁   z₃−z₁| = 0

Точки не лежат на одной прямой.

Расстояние от точки до плоскости

Формула

ρ = |Ax₀ + By₀ + Cz₀ + D| / √(A² + B² + C²)

n = {A; B; C} — вектор нормали.

Угол между прямыми

Косинус угла

cos α = |m₁ · m₂| / (|m₁| · |m₂|)

Угол между прямой и плоскостью

Синус угла

sin α = |c · n| / (|c| · |n|)

Угол между плоскостями

Косинус угла

cos α = |n₁ · n₂| / (|n₁| · |n₂|)
